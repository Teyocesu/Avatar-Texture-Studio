# Architecture

The installable UPM package is `Packages/com.teyocesu.avatar-texture-studio`. `AvatarTextureStudio.Editor` is restricted to the Editor and has no external assembly/package dependencies. There are no runtime scripts, avatar components or VRChat SDK dependencies.

`Editor/Core` retains the MIT upstream engine under `AvatarTextureStudio.Painting`. BrushEngine projects the posed mesh into texture space; PaintTarget handles geometry/UVs, ray hits, padding and temporary property-block preview; PaintDocument/PaintLayer hold RGBA8 pixels and mask data; PaintHistory bridges GPU snapshots to Unity undo. The shader arithmetic is unchanged from the pinned upstream; only shader lookup names differ. Focused failure cleanup does not replace the rendering algorithm.

`PaintSession` coordinates a renderer, multiple texture documents, history, input and preview. `PaintProjectIO` retains the MTPAINT1/2 representation, validates file headers and payloads, and copies source importer settings on new exports. `Editor/Infrastructure/SafeFileIO` supplies same-directory create/replace and PNG destination validation. The editor UI obtains explicit overwrite/assignment consent; the session export API requires an explicit overwrite flag too. No delete-then-move replacement fallback exists: an unsupported atomic replacement fails visibly and retains the prior destination.

`Editor/UI/MeshTexturePainterWindow` is the upstream-derived single application shell. Painting and Masks retain separate sessions/settings. Compare deactivates Scene view input/preview without disposing either document or history; returning reactivates the chosen session. Closing uses Unity's unsaved-window prompts. Script reload/Play transitions commit the current stroke, autosave both sessions to `Library/AvatarTextureStudio`, dispose GPU state, then restore from SessionState recovery keys. A failed restore retains its recovery file/key and reports the error. Restarting Unity requires reopening saved projects (or the Library recovery file manually); undo history is not persisted.

`Editor/TextureLab` has no painting-engine dependency. Its serializable panel holds only asset references and view/navigation state, and owns one disposable preview material. The shader samples imported mip 0; it does not read source pixels, write assets, change texture sampler/import settings, or allocate CPU pixel buffers. Imported-color mode follows sRGB/linear sampling; Raw data values reverses automatic sRGB decoding before displaying channels. Overlay composites B over A with adjustable opacity. Difference shows the absolute per-channel discrepancy, includes alpha, and labels gain/clipping. It is not an image-quality metric. Mismatched sizes remain inspectable separately; overlay/difference is blocked.

Development-only harnesses live outside the shipped package in `Tests/UnityProject` (preserved GPU tests and Studio integration regressions) and `Tests/FileSafety` (real .NET filesystem checks and syntax parsing). `tools/verify_repository.py` checks package/GUID/shader/provenance integrity; `tools/package.py` creates a local installable tarball. These do not establish Unity or GPU acceptance.

## Shot 2 boundaries and state

`Editor/Creative/Core` is plain C# using the platform's System.Numerics, IO and compression libraries, without Unity references or new packages. `UvLayout` retains source triangle/submesh/slot/channel identities, barycentric coordinates and every reverse match. It clips material-transformed UVs into Repeat/Mirror tiles while carrying source barycentric weights. Degenerate triangles remain identifiable by Scene rays but have no rasterizable UV area. Clamp/MirrorOnce border tails are explicitly many-to-one. Source triangles and sampled fragments are bounded; unsupported triangles remain in raw inspection and cannot generate a mask. Ray selection is two-sided within the selected renderer only, with nearest-depth ties retained. The kernel was executed against synthetic geometry before deriving masks from its selections.

`CreativeMeshAdapter` reads source UV0–UV7 and submesh indices, obtains posed world positions, and reuses PaintTarget's scale-aware skin bake resolution and pose hash. Those two helpers changed visibility only; their algorithms and all upstream shaders remain unchanged. Pose changes refresh geometry; explicit Refresh handles in-place mesh edits that cannot be inferred from mesh identity. No mesh, renderer asset or importer is changed. Correspondence validation is conservative: known Standard/ordinary Unlit `_MainTex` / UV0 supports material scale/offset; arbitrary/custom shader sampling stays unverified. Raw geometric coordinates remain labelled separately.

`ColorImage` and `RegionMask` own immutable RGBA8/bit arrays. Regions contain shared immutable masks plus editable names, Face flags and hue/chroma/strength. A mask selects pixel centers at baseline resolution. Triangle fill uses sampled clipped fragments, while add/subtract brush strokes rasterize a circular capsule between pointer events to avoid gaps. CreativeHistory snapshots clone metadata/configurations and share immutable pixel data. It retains at most 24 steps and 128 MiB of extra unique data, raised to the current baseline's size when necessary (at most 256 MiB) so one large rebase is reversible. Undo history is not persisted.

`ColorwayProcessor` starts with exact baseline bytes. For selected pixels only, it decodes source sRGB when needed, rotates/scales Oklab a/b at fixed L, interpolates strength, and reduces chroma radially at fixed L to fit RGB gamut. Ordered overlapping adjustments stay in floating point until one final RGBA8 quantization. Alpha is copied, unselected pixels are never re-encoded, and identity/zero-strength adjustments bypass conversion. L preservation is perceptual and subject to quantization; it is not exact physical luminance Y. The [original Oklab definition](https://bottosson.github.io/posts/oklab/) supplies the matrices. No upstream painting arithmetic changes.

`CreativeWorkspace` shares target, geometry selection, navigation, masks and adjustments among UV Explorer, Colorway and Face. It captures through the existing PaintDocument import/readback paths, releases every owned preview texture/material, and borrows PaintTarget only for restorable property blocks. Result/model textures use the saved wrap modes, generate ordinary Unity mips and follow the selected source's filtering when bound. TextureLab receives owned read-only snapshots; default asset-only validation is retained. Preview changes never assign shared materials. Switching tabs deactivates the current Scene input/preview; background paint sessions and creative state stay alive.

Face toggles the existing matching color PaintSession and displays its actual tool/layer UI. A different open painting target is retained and must be saved/stopped or adopted. Existing painting brushes retain upstream layer semantics; only Colorway uses region restrictions. Face painting blocks non-identity material scale/offset because the original engine projects raw UVs. Colorway's frozen baseline changes only on explicit Capture, and remains independent of the layer stack. This avoids a full flattened layer that would destroy editability or alter alpha by compositing twice.

## ATSCRV01 version 1

`.mtpaint` MTPAINT1/2 storage/loaders are unchanged. `.atsstudio` is self-contained and uses BinaryWriter little-endian primitives:

| Order | Contents |
| --- | --- |
| Header | Eight ASCII bytes `ATSCRV01`, Int32 version `1`, Int64 compressed byte length equal to the remaining file length. |
| Gzip body: image/binding | Int32 width/height (1–8192), one-byte sRGB bool; four Int32-byte-length UTF-8 strings for renderer hierarchy, material name, property, source path; Int32 slot/channel; two float32 vectors for scale/offset; two Int32 wrap enums. |
| Gzip body: navigation/pixels | Float32 zoom, float32 pan pair, Int32 active region; bottom-left-row RGBA8 baseline bytes (`width × height × 4`). |
| Gzip body: regions | Int32 count (0–32); each has length-prefixed UTF-8 name, one-byte enabled/Face bools, float32 hue/chroma/strength and `ceil(width × height / 8)` mask bytes, low bit first. |

Strings are checked before allocation (16 KiB encoded and 4096 decoded characters); dimensions, counts, enums, finite values, ranges, mask padding and decoded EOF are validated. Decompression is capped at 512 MiB, with 1 MiB reserved for metadata in writable documents. Compressed length is checked before decompression because an executed .NET regression showed missing gzip footer bytes can otherwise pass after all editable fields have decoded. There is no released earlier Studio sidecar to migrate. Gzip provides its ordinary integrity check, not authentication or a backup guarantee.

Loads validate a new document completely before replacing existing state or previews. Standalone Save/Open and related `<painting>.atsstudio` companions reuse SafeFileIO, including retained recovery files on replacement failures. The painting/companion pair is two separate transactions: a companion failure/cancellation leaves creative dirty and explicitly reports that the painting may already be saved. Replacing another existing companion requires confirmation. Colorway PNG export requires a new validated Assets path. Only its new importer is configured: source transfer, input alpha, no transparency color dilation/compression, enough maximum size, no NPOT scaling and recorded wrapping. Source/importer/material assets remain unchanged.

Library creative autosave stores the same format and remembers project path/dirty state in SessionState. Before Play/reload/disable, input and model preview are released and the editable document is saved; on Edit restore, failed loads retain their file/key and any current document. Restart recovery is manual, like Shot 1. No Unity object references are serialized in the sidecar; select the recorded binding explicitly after standalone/restart opening. Autosave cannot preserve new work if every write fails.

Relevant Unity 2022.3 API contracts were checked against [Mesh.GetUVs](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/Mesh.GetUVs.html), [BakeMesh](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/SkinnedMeshRenderer.BakeMesh.html), [SceneView.duringSceneGui](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/SceneView-duringSceneGui.html), [SetPixelData](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/Texture2D.SetPixelData.html), [GetPixelData](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/Texture2D.GetPixelData.html), [alphaIsTransparency](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/TextureImporter-alphaIsTransparency.html) and [NPOT scaling](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/TextureImporter-npotScale.html). These are source references, not executed Unity compatibility evidence.
